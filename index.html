1. 写真を選択

写真ライブラリから複数枚を選択できます。追加で選ぶ場合も、前に選んだ写真はアプリ内に保持されます。対応形式はブラウザが画像として読み込めるものに限ります。

2. 調整内容

0.0 EV
−2＋2

0
暗明
0 = 変更なし

調整値は選択したすべての写真に共通で適用されます。プレビューは現在選択中の先頭の写真です。

3. プレビュー・書き出し

写真を選択すると、ここにプレビューが表示されます
加工した写真はJPEGとして書き出します。元の写真は変更しません。

このアプリはブラウザ内で画像を処理します。写真をサーバーへアップロードしません。書き出し画像は新しいJPEGです。元のEXIF情報（撮影日時・位置情報など）は引き継がれない場合があります。iPhone標準「写真」アプリの非公開アルゴリズムを完全再現するものではなく、見た目を近づけるための独自調整です。
